# truenas_ssh_keypair (Resource)

Manages keypair for SSH connections.

-> Requires TrueNAS 25.0 or later.

## Example Usage

```terraform
# Generate a new public/private keypair
resource "tls_private_key" "keypair" {
  algorithm = "RSA"
  rsa_bits = 2048
}

# Create a new truenas keypair
resource "truenas_ssh_keypair" "keypair" {
  name = "keypair"
  public_key = tls_private_key.keypair.public_key_openssh
  private_key = tls_private_key.keypair.private_key_openssh
}
```

## Import

SSH keypairs can be imported using the numeric ID:

```shell
terraform import truenas_ssh_keypair.example 1
```
