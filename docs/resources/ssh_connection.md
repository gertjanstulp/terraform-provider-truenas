# truenas_ssh_connection (Resource)

Manages settings for SSH connections.

-> Requires TrueNAS 25.0 or later.

## Example Usage

```terraform
# Retrieve an existing SSH keypair
data "truenas_ssh_keypair" "keypair" {
  name = "keypair"
}

# Create a new SSH connection using the keypair
resource "truenas_ssh_connection" "connection" {
  name = "connection"
  host = "example.com"
  port = 22
  username = "username"
  private_key_id = data.truenas_ssh_keypair.keypair.id
  remote_host_key = "<some key>"
  connect_timeout = 30
}
```

## Import

SSH credentials can be imported using the numeric ID:

```shell
terraform import truenas_ssh_connection.example 1
```

- `private_key_id` (Number) ID of the SSH keypair to authenticate with the remote host.
